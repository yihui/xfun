Description

Return a logical vector indicating if elements of a character vector are blank (white spaces or empty strings).

Usage

is_blank(x)

Arguments

x

A character vector.

Value

TRUE for blank elements, or FALSE otherwise.

Examples

xfun::is_blank("")

#> [1] TRUE

xfun::is_blank("abc")

#> [1] FALSE

xfun::is_blank(c("", "  ", "\n\t"))

#> [1] TRUE TRUE TRUE

xfun::is_blank(c("", " ", "abc"))

#> [1]  TRUE  TRUE FALSE
