Description

A wrapper function to make strwrap() return a character vector of the same length as the input vector; each element of the output vector is a string formed by concatenating wrapped strings by \n.

Usage

str_wrap(...)

Arguments

...

Arguments passed to strwrap().

Value

A character vector.

Examples

x = sample(c(letters, " "), 200, TRUE, c(rep(.5/26, 26), .5))
x = rep(paste(x, collapse = ""), 2)
strwrap(x, width = 30)

#>  [1] "vx pv pspgf rrrp cm j gpubz s" "tp sdsv c m e v g tuzs b nb"  
#>  [3] "gr c o rzfi l e hnkhgi eg sz"  "sjvdibzvpn o k c q nfkh o a"  
#>  [5] "yheg hju emm o e ccr a uclaq"  "cel"                          
#>  [7] "vx pv pspgf rrrp cm j gpubz s" "tp sdsv c m e v g tuzs b nb"  
#>  [9] "gr c o rzfi l e hnkhgi eg sz"  "sjvdibzvpn o k c q nfkh o a"  
#> [11] "yheg hju emm o e ccr a uclaq"  "cel"                          

xfun::str_wrap(x, width = 30)  # same length as x

#> [1] "vx pv pspgf rrrp cm j gpubz s\ntp sdsv c m e v g tuzs b nb\ngr c o rzfi l e hnkhgi eg sz\nsjvdibzvpn o k c q nfkh o a\nyheg hju emm o e ccr a uclaq\ncel"
#> [2] "vx pv pspgf rrrp cm j gpubz s\ntp sdsv c m e v g tuzs b nb\ngr c o rzfi l e hnkhgi eg sz\nsjvdibzvpn o k c q nfkh o a\nyheg hju emm o e ccr a uclaq\ncel"
