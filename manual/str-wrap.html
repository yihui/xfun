Description

A wrapper function to make strwrap() return a character vector of the same length as the input vector; each element of the output vector is a string formed by concatenating wrapped strings by \n.

Usage

str_wrap(...)

Arguments

...

Arguments passed to strwrap().

Value

A character vector.

Examples

x = sample(c(letters, " "), 200, TRUE, c(rep(.5/26, 26), .5))
x = rep(paste(x, collapse = ""), 2)
strwrap(x, width = 30)

#>  [1] "xyb if yl r bf s z c uvku km"  "eb i e dw f mj lealuq t txbbl"
#>  [3] "e y mx m em km cwcjy qm uyb b" "f su aq ewlmky e b t ozp ph"  
#>  [5] "re sou hpp xjsxetsv n v k pk"  "b o ajv ead uy vi"            
#>  [7] "xyb if yl r bf s z c uvku km"  "eb i e dw f mj lealuq t txbbl"
#>  [9] "e y mx m em km cwcjy qm uyb b" "f su aq ewlmky e b t ozp ph"  
#> [11] "re sou hpp xjsxetsv n v k pk"  "b o ajv ead uy vi"            

xfun::str_wrap(x, width = 30)  # same length as x
