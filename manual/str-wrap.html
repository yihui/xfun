Description

A wrapper function to make strwrap() return a character vector of the same length as the input vector; each element of the output vector is a string formed by concatenating wrapped strings by \n.

Usage

str_wrap(...)

Arguments

...

Arguments passed to strwrap().

Value

A character vector.

Examples

x = sample(c(letters, " "), 200, TRUE, c(rep(.5/26, 26), .5))
x = rep(paste(x, collapse = ""), 2)
strwrap(x, width = 30)

#>  [1] "u eaz mtom kwj june q ku yvdb" "ef e qnq r qv u po j x djrhl" 
#>  [3] "o kpr xu b x o lq ki nx g rp"  "iq dttf rx dy kk cap u bmhk b"
#>  [5] "n o f kh t x pl v x s zq jnry" "j a"                          
#>  [7] "u eaz mtom kwj june q ku yvdb" "ef e qnq r qv u po j x djrhl" 
#>  [9] "o kpr xu b x o lq ki nx g rp"  "iq dttf rx dy kk cap u bmhk b"
#> [11] "n o f kh t x pl v x s zq jnry" "j a"                          

xfun::str_wrap(x, width = 30)  # same length as x

#> [1] "u eaz mtom kwj june q ku yvdb\nef e qnq r qv u po j x djrhl\no kpr xu b x o lq ki nx g rp\niq dttf rx dy kk cap u bmhk b\nn o f kh t x pl v x s zq jnry\nj a"
#> [2] "u eaz mtom kwj june q ku yvdb\nef e qnq r qv u po j x djrhl\no kpr xu b x o lq ki nx g rp\niq dttf rx dy kk cap u bmhk b\nn o f kh t x pl v x s zq jnry\nj a"
